# JavaScript verwenden

InferDI ist in TypeScript geschrieben. JavaScript-Projekte verwenden das gebaute npm-Paket über dessen Exportzuordnungen.

| Beispiel | Inhalt |
|---|---|
| [`node-esm.mjs`](https://github.com/inferdi/inferdi/blob/main/examples/javascript/node-esm.mjs) | Node-ESM-Import mit `// @ts-check` und JSDoc-Konstruktortypen |
| [`node-commonjs.cjs`](https://github.com/inferdi/inferdi/blob/main/examples/javascript/node-commonjs.cjs) | CommonJS-`require()` in Node über die Paketexports |
| [`browser-vite.js`](https://github.com/inferdi/inferdi/blob/main/examples/javascript/browser-vite.js) | Browser-ESM für Vite oder einen anderen Bundler |
