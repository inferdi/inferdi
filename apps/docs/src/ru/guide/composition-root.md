# Корень композиции

Корень композиции (composition root) находится на границе приложения: здесь выбирают конкретные реализации и связывают их друг с другом. Доменный код описывает, что ему нужно, инфраструктурный код реализует эти требования, а InferDI используется только при сборке приложения.
